# 张量变换与缓存依赖示例

在绘制维度重排、联合注意力或缓存图时使用。例子用于识别视觉误导；具体布局、轴顺序和算子应以目标实现为准。

## Patch Embedding：追踪数值与位置

采用一组一致的教学数值：批量为 1，latent 通道为 4，高宽均为 8，patch 高宽均为 2，隐藏宽度为 768。

| 阶段 | 符号形状 | 示例形状 | 实际变化 |
| --- | --- | --- | --- |
| Latent | `[B,C,H,W]` | `[1,4,8,8]` | 每个空间位置含 C 个特征 |
| 分块并重排 | `[B,H′,W′,C,p_h,p_w]` | `[1,4,4,4,2,2]` | 拆出网格坐标和块内坐标 |
| 展平块内轴 | `[B,H′,W′,Cp_hp_w]` | `[1,4,4,16]` | 每块成为一个向量 |
| 共享线性投影 | `[B,H′,W′,D]` | `[1,4,4,768]` | 特征宽度由 16 变为 768 |
| 展平网格轴 | `[B,N,D]` | `[1,16,768]` | N = H′W′，网格排成序列 |

这些是概念上的张量布局，不要求实现物化每个中间张量。线性投影的权重为 `[Cp_hp_w,D]`，偏置为 `[D]`，同一份权重用于所有样本和位置。

图示校验：

- 在原来的 8×8 网格上标出 patch 边界，不能画成未说明含义的另一张 4×4 图。
- 放大同一个 patch，展示 4 个通道、各含 2×2 个值，展平成 16 个标量，再投影成一个 768 维向量。
- embedding grid 有 16 个位置，最终也应有 16 个 token。若省略绘制，明确使用省略号并标出总数。
- reshape 和轴重排保持数值总量。线性投影改变数值和特征数，不遵循这个数量守恒。
- 展平保存位置的可逆索引映射，但 Attention 仍需相应的位置表示才能使用空间信息。

卷积核和步幅等于 patch 大小、无填充时，Conv2d 可合并切分与投影。实现布局常为 `[B,D,H′,W′]`，再展平空间轴、交换轴得到 `[B,N,D]`。这条等价实现路径适合放在一个注记中；不必再复制整套概念流程。

## 双流注意力：用边界判断是否画对

假设图像与文本分别有 N_i、N_t 个 token，注意力内部投影宽度一致：

- 分别生成两路 Q、K、V；参数是否共享由实现决定。
- 沿序列轴拼接，联合长度为 N_i + N_t；特征宽度不因这次拼接而翻倍。
- 若实现是完整联合注意力，权重的两个位置轴均为 N_i + N_t；四个区域对应两种 Query 与两种 Key 的组合。
- 若按图像在前、文本在后的顺序拼接，输出在序列位置 N_i 处拆开，分别进入各自的后续路径。

只有实现确实允许相应关系时才画四个区域。最后一层若停止更新某一路状态，应明确“仍参与当前注意力”与“无需产生供下一层使用的状态”的区别，不把整个模态输入删掉。

## Condition Cache：从完整依赖推导复用

以类别条件模型为例，固定类别向量记作 e_y，时间步编码记作 e_t。全局条件 c(t) 由两者相加得到。图上必须有两条输入边，不能只画固定类别到 c(t) 的箭头。

| 对象 | 完整依赖 | 可以说明的复用方式 |
| --- | --- | --- |
| 类别编码 e_y | 类别、编码权重 | 类别与权重固定时跨步复用 |
| 条件 c(t) | 时间步、类别、编码权重 | 所需时间步已知时逐步预计算 |
| 某层调制参数 | c(t)、该层映射权重 | 按 step、按层分别保存 |
| 当前图像或已交互文本状态 | 当前输入、此前的交互计算 | 不能仅因原始条件固定就视为静态 |

缓存图区分“条件准备”与“本次前向计算”，缓存读取边接到实际使用系数的操作上。共享条件向量不等于各层共享映射参数；预计算也不等于将 LayerNorm、Attention 的结果变为常量。

分析双流模型时，分别检查初始编码、初始投影、首层进入交互之前的状态，以及后续层状态。即使某一路来自固定文本，经过图像交互后仍可能依赖当前图像。不要笼统声称全部文本 K/V 可跨步缓存。

预计算说明应回答：权重、条件、时间表是否确定；准备成本是多少；缓存存什么、占多少空间；同一结果实际读取几次。只使用一次的结果通常是计算时机前移，不能据此声称获得加速。跨步复用动态状态属于近似策略，应单独说明误差与评估需求。
