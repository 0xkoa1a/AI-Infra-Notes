# FlashAttention v1

## 标准 Attention 的问题

为简化表达，下面忽略 Batch 和 Head 维度，只讨论一个 Attention Head。设：

$$Q,K,V\in\mathbb{R}^{N\times d}$$

其中：

* $N$ 是序列长度；
* $d$ 是 Head Dimension。

Scaled Dot-Product Attention 为：

$$S=\frac{QK^\top}{\sqrt d},\qquad P=\operatorname{softmax}(S),\qquad O=PV$$

其中：

$$S,P\in\mathbb{R}^{N\times N},\qquad O\in\mathbb{R}^{N\times d}$$

标准实现通常分成三个阶段：

```text
QK^T → 将 S 写入 HBM
          │
          ▼
Softmax → 读取 S，将 P 写入 HBM
          │
          ▼
PV      → 读取 P 和 V，写回 O
```

$QK^\top$ 和 $PV$ 是计算密集的矩阵乘；Softmax、Mask 等操作则需要反复读取和写入中间结果。随着 $N$ 增长，完整的 $S$ 和 $P$ 都包含 $N^2$ 个元素，其显存占用和 HBM 流量会迅速成为瓶颈。

FlashAttention v1 的目标不是减少 Attention 的主要计算量，而是避免在 HBM 中 materialize 完整的 $S$ 和 $P$。

---

## Tiling 与 Kernel Fusion

FlashAttention 将输入沿着序列维度切成能够放入 SRAM 的 tile。每个 tile 包含部分的序列和完整的 head dimension：

$$Q_i\in\mathbb{R}^{B_r\times d},\qquad K_j,V_j\in\mathbb{R}^{B_c\times d}$$

每次只在片上计算一个局部 Score Block：

$$S_{ij}=\frac{Q_iK_j^\top}{\sqrt d}\in\mathbb{R}^{B_r\times B_c}$$

对于每一个 $Q_i$ tile，算法沿 Key/Value 序列维度以宽度 $B_c$ 逐 Tile 迭代。每轮都会更新目前为止的逐行最大值，并根据当前 $S_{ij}$ 和 $V_j$ 计算一个形状为 $[B_r,d]$ 的输出 partial sum。已有的归一化输出 $O_i\in\mathbb{R}^{B_r\times d}$ 先乘回旧分母 $l_i$，还原成未归一化的 Accumulator；这个 Accumulator 按新的逐行最大值缩放后，与当前 Tile 的 partial sum 相加，最后再除以新的累计分母。

Tiling 让工作集能够留在 SRAM，避免了 $S_{ij}$ 和局部概率矩阵在 HBM 中往返。

FlashAttention 只是改变计算顺序和中间结果的存放位置，因此结果仍是精确 Attention。

## Online Softmax

对于一个 Query Tile 和一个 KV Tile：

$$Q_i\in\mathbb{R}^{B_r\times d},\qquad K_j,V_j\in\mathbb{R}^{B_c\times d}$$

局部 Score Tile 为：

$$S_{ij}=\frac{Q_iK_j^\top}{\sqrt d}\in\mathbb{R}^{B_r\times B_c}$$

$S_{ij}$ 的每一行对应一个 Query，$B_c$ 列对应当前 KV Tile 中的 Key。Online Softmax 沿 $B_c$ 维处理这个 Tile。

处理当前 $K_j,V_j$ 之前，每个 Query Tile $Q_i$ 使用三个状态概括已经处理过的所有 KV Tile：

* $m_i\in\mathbb{R}^{B_r}$：每个 Query Row 目前见过的最大 Score，用作稳定计算指数的基准；
* $l_i\in\mathbb{R}^{B_r}$：每个 Query Row 在该基准下累积的指数和，也就是当前归一化分母；
* $O_i\in\mathbb{R}^{B_r\times d}$：每个 Query Row 对已经处理过的 Value 得到的归一化输出。

现在处理新的 $S_{ij}$。先计算当前 Tile 自己的逐行最大值：

$$\widetilde m_{ij}=\operatorname{rowmax}(S_{ij})\in\mathbb{R}^{B_r}$$

减去逐行最大值后计算指数：

$$\widetilde P_{ij}
=
\exp\left(S_{ij}-\widetilde m_{ij}[:,\mathrm{None}]\right)
\in\mathbb{R}^{B_r\times B_c}$$

这里的 $\widetilde P_{ij}$ 只是当前 Tile 的未归一化权重。对应的逐行指数和为：

$$\widetilde l_{ij}
=
\operatorname{rowsum}(\widetilde P_{ij})
\in\mathbb{R}^{B_r}$$

旧状态使用 $m_i$ 作为指数基准，当前 Tile 使用 $\widetilde m_{ij}$ 作为指数基准。为了让两部分能够相加，先逐行取两者的最大值作为新的共同基准：

$$m_i'=\max(m_i,\widetilde m_{ij})\in\mathbb{R}^{B_r}$$

然后分别计算旧状态和当前 Tile 到新基准的缩放系数：

$$\alpha_{ij}=\exp(m_i-m_i'),\qquad
\beta_{ij}=\exp(\widetilde m_{ij}-m_i')$$

$\alpha_{ij},\beta_{ij}\in\mathbb{R}^{B_r}$，其中每个元素对应一个 Query Row 的缩放系数。

对于旧状态中的任意 Score，将指数基准从 $m_{i,r}$ 改成 $m_{i,r}'$，等价于将原来的指数值乘以 $\alpha_{ij,r}$：

$$e^{s_{i,r,k}-m_{i,r}'}
=
e^{m_{i,r}-m_{i,r}'}e^{s_{i,r,k}-m_{i,r}}
=
\alpha_{ij,r}e^{s_{i,r,k}-m_{i,r}}$$

当前 Tile 中的指数值同理乘以 $\beta_{ij}$。缩放后，两部分处于同一个指数尺度，因此新的累计分母为：

$$l_i'
=
\alpha_{ij}\odot l_i+
\beta_{ij}\odot\widetilde l_{ij}
\in\mathbb{R}^{B_r}$$

这里的 $\odot$ 表示两个长度为 $B_r$ 的向量逐元素相乘。这个更新把旧状态和当前 Tile 的指数和都换算到 $m_i'$ 对应的尺度，再得到新的归一化分母。

由于 $O_i$ 是已经归一化的输出，旧状态在原尺度下的未归一化 Value 加权和是 $l_{i,r}O_{i,r,:}$。当前 Tile 在自身尺度下的未归一化 Value 加权和为：

$$\widetilde P_{ij}V_j\in\mathbb{R}^{B_r\times d}$$

将旧加权和乘以 $\alpha_{ij,r}$，将当前 Tile 的加权和乘以 $\beta_{ij,r}$，便可在新尺度下相加。对每个 Query Row $r$，新的归一化输出为：

$$O_{i,r,:}'
=
\frac{
\alpha_{ij,r}l_{i,r}O_{i,r,:}+
\beta_{ij,r}(\widetilde P_{ij}V_j)_{r,:}
}{l_{i,r}'}$$


所有 KV Tile 处理完成后，状态 $O_i$ 已经包含整个 Key/Value 序列对 $Q_i$ 的贡献，因此就是完整 Attention 对应的输出。

## Forward 的完整流程

FlashAttention v1 在 HBM 中初始化：

$$O=0,\qquad l=0,\qquad m=-\infty$$

前向采用 KV Block 作为外层循环，Query Block 作为内层循环：

```text
for each K_j, V_j Block
    将 K_j, V_j 从 HBM 加载到 SRAM

    for each Q_i Block
        从 HBM 加载 Q_i, O_i, m_i, l_i
        计算局部 S_ij = Q_i K_j^T / sqrt(d)
        更新 m_i, l_i 和 O_i
        将 O_i, m_i, l_i 写回 HBM
```

对应的数据流为：

```text
K_j, V_j 进入 SRAM
        │
        ├── Q_1 → S_1j → Online Softmax → 更新 O_1, m_1, l_1
        ├── Q_2 → S_2j → Online Softmax → 更新 O_2, m_2, l_2
        │   ...
        └── Q_Tr → S_Tr,j → Online Softmax → 更新 O_Tr, m_Tr, l_Tr
        │
        ▼
切换到下一组 K_j, V_j
```

这样，一个 $K_j,V_j$ Block 加载到 SRAM 后，可以依次服务所有 Query Block。每处理完一对 $(Q_i,K_j,V_j)$，局部 $S_{ij}$ 就被丢弃，只保留更新后的 $O_i,m_i,l_i$。

当所有 KV Block 都处理完后，$O_i$ 已经是完整、归一化后的 Attention 输出，不需要再次读取完整 Score 或执行一次全局 Softmax。

对于 Causal Attention，先在局部 $S_{ij}$ 中将未来位置设为 $-\infty$，再执行 Online Softmax。完全位于因果边界之外的 Block 不产生贡献，可以直接跳过。

## 收益与边界

FlashAttention v1 在 HBM 中保留的是 $Q,K,V,O$ 和逐行状态 $m,l$，不保存完整的 $S$ 和 $P$。因此 Attention 中间状态从 $O(N^2)$ 降为 $O(N)$，整体激活存储由 $Q,K,V,O$ 这类 $O(Nd)$ 张量主导。

其主要计算复杂度仍然是：

$$O(N^2d)$$

性能收益来自减少 HBM 访问，而不是跳过 Attention 计算：

* Score、Mask、Softmax 和输出更新在片上连续完成；
* $N\times N$ 的 Score 和概率矩阵不再写入、读出 HBM；
* 更多工作发生在高带宽的 SRAM 中，矩阵乘之间的访存开销显著降低。

代价与限制包括：

* Block 必须足够小，使 $Q_i,K_j,V_j,S_{ij}$ 和 Softmax 状态能够同时放入 SRAM；
* Head Dimension 越大，单个 Token 占用的片上空间越多，可选 Block 越小；
* KV-outer 调度会为每个 KV Block 重新读取并写回各个 $Q_i,O_i,m_i,l_i$，并没有消除所有 HBM 流量；
* Online Softmax 会增加少量逐行归约和缩放操作，但通常远小于省下的 HBM 访问成本。

FlashAttention v1 的核心可以概括为：用 Tiling 控制片上工作集，用 Online Softmax 保证分块计算仍然精确，再通过 Fusion 避免二次规模的 Attention 中间矩阵落入 HBM。
