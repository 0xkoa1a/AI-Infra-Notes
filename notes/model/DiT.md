# DiT：Diffusion Transformer

DiT 用 Transformer 处理带噪图像，并预测一次去噪更新所需的信息。本文介绍原始类别条件 DiT：模型接收当前图像状态、噪声时间步和目标类别，预测噪声及反向采样的方差参数。

## 生成任务与 DiT 的作用

生成图像时，模型从随机噪声出发，经过多次更新，逐渐得到有结构的图像。为了减少计算，DiT 通常处理图像经过压缩后的表示，称为 **latent**。它保留通道、高和宽三个轴，但空间尺寸通常比最终图像小。

一次生成由三个部分配合完成：

- **DiT**：读取当前带噪 latent，预测本次更新所需的信息。调用一次网络称为一次前向计算。
- **Scheduler（采样器）**：根据网络预测和选定的采样规则，计算下一步 latent，并推进时间步。
- **VAE Decoder（解码器）**：在采样结束后，将最终 latent 还原成图像。

DiT 先把 latent 划分成小块，每块称为一个 **patch**；再把每块变成一个向量，每个向量称为一个 **token**。Transformer 通过 Attention 让每个位置读取其他位置的信息，例如让物体的一部分参考远处的轮廓。各层持续更新这些特征，最后将结果重新排回二维空间。切成 token 后，图像就可以使用标准的 Transformer 主干；patch 大小则决定了模型处理空间细节的粒度和计算量。

**训练直觉。** 训练时，先用 VAE Encoder 把真实图像变成干净 latent，再随机选择时间步、加入已知噪声。模型读取带噪 latent、时间步和类别，并学习让噪声预测接近加入的那份噪声。方差分支使用单独的分布匹配训练项，学习反向采样所需的方差。生成时，从随机噪声开始，反复调用训练好的模型和采样器。

## 模型输入：图像 token 与条件

### Patchify

Patchify 把二维空间组织成 Transformer 需要的 token 序列。它先在原 latent 上划分互不重叠的 patch，保留每块内部的通道和空间坐标，再逐块展开、投影，最后把 patch 网格排成序列。

尺寸关系如下：

- $p_h,p_w$：一个 patch 的高、宽，要求分别整除 $H_l,W_l$。
- $H'=H_l/p_h$、$W'=W_l/p_w$：切分后的 patch 网格高、宽。
- $N_i=H'W'$：图像 token 数，即 patch 总数。

切分时，空间轴拆成“patch 在哪里”和“patch 内部的位置”。例如，高度 $H_l$ 拆成网格高度 $H'$ 与块内高度 $p_h$，宽度也按同样方式拆分。这个过程只重新组织数值，尚未产生新特征。

所有 patch 共用一个线性投影。为看清空间位置如何保留，先让 patch 按二维网格排列：

- $P$：每个 patch 展平后的向量，整体形状为 $[B,H',W',Cp_hp_w]$。
- $W_{\mathrm{patch}}$：可学习的投影矩阵，形状为 $[Cp_hp_w,D]$。
- $b_{\mathrm{patch}}$：投影偏置，形状为 $[D]$，沿样本和两个网格轴广播。
- $G$：投影后的 embedding 网格，形状为 $[B,H',W',D]$。
- $E$：将 $G$ 的两个网格轴展平后得到的序列，形状为 $[B,N_i,D]$。

线性投影只改变每个 patch 的特征数，保留样本数和 patch 的网格位置：

$$
G=PW_{\mathrm{patch}}+b_{\mathrm{patch}}.
$$

“广播”表示将同一个较小张量用于多个位置，无需为每个位置保存一份独立参数。这里所有样本、所有 patch 共用同一份偏置。

| 阶段 | 形状 | 操作改变什么 |
| --- | --- | --- |
| 输入 latent | $[B,C,H_l,W_l]$ | 每个空间位置有 $C$ 个特征 |
| 划分 patch，并重排轴 | $[B,H',W',C,p_h,p_w]$ | 显式分开网格位置与 patch 内部坐标 |
| 展平每个 patch | $[B,H',W',Cp_hp_w]$ | 只合并块内的通道、高和宽 |
| 逐 patch 线性投影 | $[B,H',W',D]$ | 每块的 $Cp_hp_w$ 个输入值变成 $D$ 个特征 |
| 展平网格位置 | $[B,N_i,D]$ | 只合并 $H',W'$ 两个轴，$N_i=H'W'$ |

空间位置通过固定顺序映射到序列位置。按行展平时，这个映射为：

- $u,v$：从零开始的 patch 行、列坐标。
- $n=uW'+v$：从零开始的序列位置。

因此，展平没有丢弃空间位置，只是将两个坐标合并成一个索引。后续位置编码再把二维坐标信息显式提供给 Attention。

> 本文按通道、块内行、块内列的顺序展开一个 patch。展平顺序需要与投影矩阵的输入排列一致。示例中的 $D=768$ 仅用于说明形状变化；实际模型可以使用其他隐藏宽度。

减小 patch 会增加 token 数，让模型处理更细的空间区域，也增加后续计算量。本文用高、宽分别表示尺寸；原始 DiT 使用方形 patch，并按方形网格还原输出。

### 二维位置编码

展平成序列后，模型仍需要知道每个 token 原来位于哪一行、哪一列。位置编码将这两个坐标分别转换成向量，再拼接成一个 $D$ 维位置向量。

原始 DiT 使用固定的正弦、余弦编码。相关记号如下：

- $u,v$：patch 的行、列坐标。
- $\psi(q)$：坐标 $q$ 的编码，包含 $D/2$ 个特征。
- $\nu_k=10000^{-k/(D/4)}$：第 $k$ 个固定频率，其中 $k=0,\ldots,D/4-1$。
- $P_{\mathrm{pos}}$：所有位置的编码，形状为 $[1,N_i,D]$。

$\psi(q)$ 先排列所有频率上的正弦值，再排列余弦值。列、行编码各占一半特征；这里要求 $D$ 是 $4$ 的倍数：

$$
\psi(q)=\bigl([\sin(q\nu_k)]_k\ ;\ [\cos(q\nu_k)]_k\bigr),
\qquad
P_{\mathrm{pos}}[u,v]=[\psi(v);\psi(u)].
$$

分号表示沿特征轴拼接。将位置编码按与 patch 相同的顺序展平后，与图像 token 逐位置相加，得到第一个 Block 的输入：

$$
X^0=E+P_{\mathrm{pos}}\in\mathbb R^{B\times N_i\times D}.
$$

上标 $0$ 表示进入第一个 Block 之前的状态。位置编码只沿批量轴 $B$ 广播，因此同一位置在所有样本中使用同一个位置向量；token 数不变。

固定网格的位置编码可以复用。更换分辨率时，patch 网格和位置编码都要匹配，模型也需要支持相应的输入尺寸。

### 时间步与类别条件

时间步告诉网络当前处于哪个噪声水平，类别告诉网络希望生成什么。它们分别编码，再相加。

- $t$：时间步输入，形状为 $[B]$。
- $D_\tau$：时间步正弦、余弦编码的特征数。
- $\phi_t$：时间步的正弦、余弦编码，形状为 $[B,D_\tau]$。
- $e_t$：时间步编码经过 MLP 后的结果，形状为 $[B,D]$。
- $y$：目标类别的索引，形状为 $[B]$。
- $e_y$：根据类别索引从可学习的表中取出的向量，形状为 $[B,D]$。

时间步编码对每个固定频率分别计算余弦和正弦，再沿特征轴拼接。对于偶数 $D_\tau$：

$$
\phi_t=\bigl([\cos(t\omega_k)]_k\ ;\ [\sin(t\omega_k)]_k\bigr),
\qquad
\omega_k=10000^{-k/(D_\tau/2)},\quad k=0,\ldots,D_\tau/2-1.
$$

随后通过“线性映射 → SiLU 激活 → 线性映射”，将宽度从 $D_\tau$ 变成 $D$，得到 $e_t$。两次映射使用以下参数：

- $W_1$、$b_1$：第一次映射的权重和偏置，形状分别为 $[D_\tau,D]$、$[D]$。
- $W_2$、$b_2$：第二次映射的权重和偏置，形状分别为 $[D,D]$、$[D]$。
- $h_t$：第一次映射再经过 SiLU 后的中间结果，形状为 $[B,D]$。

两次映射分别为：

$$
h_t=\operatorname{SiLU}(\phi_tW_1+b_1),\qquad e_t=h_tW_2+b_2.
$$

SiLU 是对每个数单独应用的非线性函数，定义为 $\operatorname{SiLU}(x)=x/(1+e^{-x})$，不改变张量形状。

将两路 $[B,D]$ 向量逐元素相加，得到所有 Block 共用的全局条件 $c(t)$：

$$
c(t)=e_t+e_y\in\mathbb R^{B\times D}.
$$

所有 Block 使用同一个 $c(t)$，但每层有自己的条件映射参数。固定类别时，$e_y$ 可以跨去噪步复用；$e_t$ 和 $c(t)$ 随时间步变化。

## 一个 DiT Block 如何更新图像

Block 接收当前图像特征和全局条件。图像特征会在层间不断更新，也称为 **hidden state（隐藏状态）**。Attention 让位置之间交换信息，MLP 再单独加工每个位置的特征。两部分计算都将结果加回原输入，这条保留输入的路径称为残差连接。

- $X$：当前图像隐藏状态，形状为 $[B,N_i,D]$。
- $c(t)$：当前时间步的全局条件，形状为 $[B,D]$。
- $\ell$：当前层的编号，从 $0$ 到 $L-1$。
- $X^\ell$：经过前 $\ell$ 层后的状态；第 $\ell$ 层将它更新为 $X^{\ell+1}$。

每层包含两个顺序相接的子层：

- **Attention 子层**：AdaLN → Self-Attention → Gate → 加回该子层输入。
- **MLP 子层**：AdaLN → MLP → Gate → 加回该子层输入。

下文先解释条件调制和两类子层，完整 Block 图放在这些机制之后。

### AdaLN 与 adaLN-Zero

**AdaLN 让条件决定特征如何缩放和平移。** 它先进行 LayerNorm：对每个样本的每个 token，沿最后的 $D$ 轴计算均值和方差，减去均值，再除以加了稳定项后的标准差。这个过程将不同 token 的特征尺度调整到便于后续计算的范围。

原始 DiT 的 LayerNorm 不额外学习固定的缩放和平移参数；这两项由当前条件生成：

- $s$：scale，控制各特征的缩放。
- $b$：shift，控制各特征的平移。
- $g$：gate，控制子层输出加回主干的幅度。
- $\odot$：逐元素相乘。

三组系数各为 $[B,D]$。使用时插入长度为一的 token 轴，变成 $[B,1,D]$，沿 $N_i$ 轴广播。因此，同一样本的所有 token 使用同一组系数，但被调制的特征不同。

归一化后，按条件缩放和平移：

$$
\widehat X=\operatorname{LN}(X)\odot(1+s)+b.
$$

这里 $\widehat X$ 是调制后的特征，形状仍为 $[B,N_i,D]$。把 Attention 或 MLP 子层记为 $\mathcal F$，先计算它的输出，再乘以 Gate，最后加回输入：

$$
X_{\mathrm{new}}=X+g\odot \mathcal F(\widehat X).
$$

Attention 和 MLP 分别需要一组 scale、shift、gate。每个 Block 对 $c(t)$ 做 SiLU，再投影成 $[B,6D]$，沿特征轴拆成六个 $[B,D]$ 张量。图中的下标 $a$ 表示 Attention 使用的系数，下标 $m$ 表示 MLP 使用的系数。

Attention 更新完隐藏状态后，MLP 会重新归一化这个新状态，再使用自己的调制系数。两次残差分别保留各自子层的输入。

adaLN-Zero 将上述条件投影的权重和偏置初始化为零。初始 Gate 为零，两个残差分支暂时不改变输入，Block 从恒等映射开始学习。训练后 Gate 可以变成非零值，推理时仍需要计算这些分支。

### Self-Attention 与 MLP

Self-Attention 让每个图像位置根据内容选择要读取的其他位置。它从调制后的特征中，用三个可学习的线性映射生成：

- $Q$（Query）：当前位置想寻找什么信息。
- $K$（Key）：各位置用来与查询匹配的特征。
- $V$（Value）：各位置实际提供的信息。

每个 Query 与所有 Key 比较得到分数，softmax 将这些分数转换成和为一的权重，再用权重汇总 Value。多头注意力将特征拆成多组，每组独立完成这次计算。尺寸记号如下：

- $n_h$：注意力头数，要求 $D$ 能被 $n_h$ 整除。
- $d_h=D/n_h$：每个头的特征数。

| 阶段 | 形状 | 轴的含义 |
| --- | --- | --- |
| Q、K、V 各自投影后 | $[B,N_i,D]$ | 样本、图像位置、特征 |
| 各自拆分多头后 | $[B,n_h,N_i,d_h]$ | 每个头处理全部位置，$d_h=D/n_h$ |
| 注意力权重 | $[B,n_h,N_i,N_i]$ | 最后两轴分别是 Query 位置和 Key 位置 |
| 加权汇总 V 后 | $[B,n_h,N_i,d_h]$ | 每个 Query 得到一组输出特征 |
| 合并多头并输出投影 | $[B,N_i,D]$ | 恢复主干形状，接 Gate 和残差 |

记注意力权重为 $A$，每个头的计算是：

$$
A=\operatorname{softmax}_{\mathrm{Key}}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_h}}\right),
\qquad O=AV.
$$

转置符号 $\mathsf T$ 交换 Key 的位置轴与特征轴，保留批量和头数。除以 $\sqrt{d_h}$ 用于控制分数的尺度；softmax 沿最后的 Key 轴进行。每个图像位置都能读取全部图像位置，因此这里没有“只能看前面位置”的限制。实际内核可以分块计算，不必把完整权重矩阵保存到显存。

MLP 在最后的特征轴上执行“线性映射 → GELU 激活 → 线性映射”。用 $r$ 表示中间层的扩展倍数，先将宽度扩展到 $rD$，再缩回 $D$；GELU 逐元素引入非线性，不改变形状。图像 token 数始终不变：

$$
[B,N_i,D]\rightarrow[B,N_i,rD]\rightarrow[B,N_i,D].
$$

MLP 不直接混合不同位置的信息；位置之间的交流发生在 Attention 中。

## 模型输出：Final Layer 与 Unpatchify

经过 $L$ 个 Block 后，图像序列仍为 $[B,N_i,D]$。最终输出层先做条件归一化：由 $c(t)$ 生成 $[B,2D]$，拆成 scale 和 shift，再沿 token 轴广播。图中这两组系数记为 $s_f,b_f$，下标 $f$ 表示最终输出层。这个阶段没有 Gate 和残差连接。

随后，线性投影把每个 token 变成一个展开的输出 patch。图中的输出投影使用以下记号：

- $C_{\mathrm{out}}$：网络输出的通道数。
- $F$：最终条件归一化后的 token，形状为 $[B,N_i,D]$。
- $W_{\mathrm{out}}$、$b_{\mathrm{out}}$：输出投影的权重和偏置，形状分别为 $[D,p_hp_wC_{\mathrm{out}}]$、$[p_hp_wC_{\mathrm{out}}]$。
- $R=FW_{\mathrm{out}}+b_{\mathrm{out}}$：展开后的输出 patch 序列。

Unpatchify 按原网格将这些 patch 放回空间位置：

| 阶段 | 形状 | 作用 |
| --- | --- | --- |
| Final Linear | $[B,N_i,p_hp_wC_{\mathrm{out}}]$ | 为每个位置预测一个输出 patch |
| Reshape | $[B,H',W',p_h,p_w,C_{\mathrm{out}}]$ | 恢复网格坐标、patch 内坐标与通道 |
| Permute | $[B,C_{\mathrm{out}},H',p_h,W',p_w]$ | 把通道放在前面，将相关空间轴放到一起 |
| 合并空间轴 | $[B,C_{\mathrm{out}},H_l,W_l]$ | 将 $H'p_h$ 合成高，将 $W'p_w$ 合成宽 |

Unpatchify 只重新排列数值。模型学习的预测映射发生在线性投影中。

主图使用同时预测噪声和方差参数的配置，因此 $C_{\mathrm{out}}=2C$。前 $C$ 个通道与后 $C$ 个通道分别交给采样器使用；只有噪声预测的配置则输出 $C$ 个通道。

## DDPM：均值、方差与随机噪声

DDPM 根据网络输出构造下一步 latent 的概率分布，再从这个分布中采样。它接收当前 latent 和网络输出；其中网络输出沿通道轴分为两组：

- $\hat\epsilon$：模型估计的噪声，形状为 $[B,C,H_l,W_l]$。
- $\hat v$：模型给出的方差参数，形状同上；它还需要转换成实际方差。

采样器用这些输出和当前 latent 计算下一步分布：

- $\mu_\theta$：下一步分布的均值，可理解为下一步 latent 的中心位置。
- $\sigma_\theta^2$：下一步分布的方差，控制围绕均值随机采样的幅度。

下标 $\theta$ 表示结果依赖模型的可学习参数。本文将采样链编号为 $T,T-1,\ldots,1$，最后得到 $z_0$。计算还需要一组预先确定的时间表系数：

- $T$：采样步数。
- $\beta_t$：与当前采样链对应的前向加噪过程在第 $t$ 步使用的噪声方差。
- $\alpha_t=1-\beta_t$：该步对应的信号保留系数。
- $\bar\alpha_t=\prod_{j=1}^{t}\alpha_j$：从第 $1$ 步到第 $t$ 步的累计系数，约定 $\bar\alpha_0=1$。

这些系数描述噪声与信号的比例。在前向加噪过程中，干净 latent 的幅度乘以 $\sqrt{\bar\alpha_t}$，标准噪声的幅度乘以 $\sqrt{1-\bar\alpha_t}$。反向采样使用同一组系数解释模型的噪声预测。

给定 $z_t$ 和 $\hat\epsilon$，下一步的均值为：

$$
\mu_\theta=\frac{1}{\sqrt{\alpha_t}}
\left(z_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\hat\epsilon\right).
$$

方差采用对数形式计算。先将模型输出转换为系数 $a$，再用它组合两端的对数方差：

- $a=(\hat v+1)/2$：与 latent 同形状的组合系数。
- $\tilde\beta_t$：已知干净 latent 和当前带噪 latent 时，前一步分布的方差，称为前向过程的后验方差。
- $\log$：自然对数；对应的逆运算为指数函数 $\exp$。

$$
\tilde\beta_t=\beta_t\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t},
$$

$$
\log\sigma_\theta^2=a\log\beta_t+(1-a)\log\tilde\beta_t.
$$

当 $a$ 位于 $[0,1]$ 内时，这是两端对数方差之间的插值。这里沿用的学习方差参数化不会额外把 $a$ 裁剪到这个区间。

均值和方差都是 $[B,C,H_l,W_l]$。每个样本的时间表系数沿通道、高和宽三个轴广播。生成下一步时，先采样与 latent 同形状的标准高斯噪声，再按标准差缩放：

- $\xi$：每个元素独立采样的噪声，均值为零、方差为一。
- $\mathcal N(0,I)$：上述标准高斯分布，$I$ 表示单位协方差。
- $\sigma_\theta=\exp(\tfrac12\log\sigma_\theta^2)$：标准差，即方差的平方根。

$$
z_{t-1}=\mu_\theta+\sigma_\theta\odot\xi,
\qquad \xi\sim\mathcal N(0,I).
$$

在最后一步 $t=1$，直接取均值，不再加入随机噪声。最终的 $z_0$ 按 VAE 的缩放约定送入 Decoder，生成图像。

> **末步方差的实现细节。** 此时 $\tilde\beta_1=0$；实现计算对数方差时，会用下一项有效后验方差的对数替代这一项，避免计算 $\log 0$。由于末步关闭随机噪声，这个替代值不会改变输出。

> 上面的均值式采用“预测噪声，且不裁剪估计出的干净 latent”的约定。减少采样步数时，需要重新计算采样链的时间表系数，并将网络接收的时间步映射回训练时的编号。数学编号与代码中从零开始的数组下标也要区分。

实际生成还可以使用 **classifier-free guidance（CFG，无分类器引导）**：对同一个带噪 latent，分别计算有目标类别和无类别条件的预测，再加强两者差异所指向的条件信号。这样通常需要额外的网络计算。主图展示一次条件前向；如果把两个分支合并到一个批量中，$B$ 就包含这两个分支的样本。

## 进阶：推理计算与缓存

### 计算规模与去噪步依赖

Attention 比较每一对 token，因此主要注意力计算随 token 数的平方增长。线性投影和 MLP 逐 token 处理特征，计算量随 token 数线性增长。以下用 $O(\cdot)$ 表示忽略常数后的增长规模：

| 部分 | 计算规模 | 主要扩展因素 |
| --- | --- | --- |
| QK 比较与对 V 的加权汇总 | $O(BN_i^2D)$ | 图像 token 数的平方 |
| QKV 与输出投影 | $O(BN_iD^2)$ | token 数与隐藏宽度 |
| MLP | $O(BrN_iD^2)$ | token 数与中间宽度 |

缩小 patch 会增加所有子层的工作量，其中 Attention 增长更快。总耗时还取决于计算内核效率、显存读写和网络前向次数。

每次采样更新后，整个 latent 都可能变化，下一次前向中的图像 token 也随之变化。能否复用某个中间结果，要看它是否依赖当前图像状态。

### Condition Cache：静态条件与调制预计算

**Condition Cache 保存只依赖条件的计算结果，减少后续重复准备的工作。** 下面根据输入依赖分析可复用的部分；这是可考虑的优化方案，不代表原始 DiT 已经实现这些缓存。

<DiTDiagram view="cache" />

固定类别时，类别向量 $e_y$ 可以跨去噪步复用。如果将要使用的时间步已经确定，还可以提前计算每一步的 $c(t)$，再经过各层的条件映射，保存对应的 scale、shift、gate。不同时间步、不同层使用各自的结果。

| 结果 | 依赖什么 | 可复用或预计算的范围 |
| --- | --- | --- |
| 类别向量 $e_y$ | 类别、类别编码权重 | 固定类别和权重时跨步复用 |
| 条件向量 $c(t)$ | 时间步、类别、条件编码权重 | 对已知时间表逐步预计算 |
| 第 $\ell$ 层调制参数 | $c(t)$、该层条件映射权重 | 按时间步和层准备，每层为 $[B,6D]$ |
| 最终输出层调制参数 | $c(t)$、输出层条件映射权重 | 按时间步准备 $[B,2D]$ |
| LayerNorm、QKV、Attention、MLP 的结果 | 当前图像隐藏状态 | 随当前前向重新计算 |

预计算要求权重固定，且相同输入总能得到相同结果。类别、权重或时间表变化时，需要更新相应缓存。若采样器根据中途结果决定下一次求值时间，就只能等时间确定后再准备对应条件。使用 CFG 时，也要分别处理有条件与无条件分支。

缓存需要额外存储。相关计数如下：

- $S$：一次采样中实际调用网络的次数。
- $L$：每次前向包含的 Block 数。
- $B,D$：实际前向批量和隐藏宽度。

全部 Block 的六组调制参数可以按 $[S,L,B,6,D]$ 保存，最终输出层再保存 $[S,B,2,D]$。存储量随 $SLBD$ 增长。这里没有计算相同条件之间的去重或共享。

如果每个结果只使用一次，预计算只是把计算移到循环之前。批量准备条件可能减少循环中的小算子开销；多次生成共用条件时，才有进一步减少重复计算的机会。是否缩短总耗时，需要同时测量准备、存储读取和实际复用的收益。

将已经随图像变化的隐藏状态直接跨步复用，会引入近似误差，需要单独评估。
